# ToZ · 让开始有迹可循

Windows 离线待办客户端、透明浮窗及安装包，保留浏览器设计原型，预留未来 iOS。

新会话从 [项目现状与开发入口](docs/项目现状.md) 开始，了解当前能力、数据契约、代码入口和未实现范围；后续开发按 [文档维护规范](docs/文档维护规范.md) 同步对应说明；每轮完成验证后自动本地提交并推送到当前分支的上游，交付时报告文档、提交和远程核对结果。

## Windows 安装版

安装包：`dist/ToZ-Setup-0.4.9-x64.exe`。可选择安装目录、桌面/开始菜单快捷方式和开机自启动；客户端设置也可修改启动、托盘与浮窗行为。安装版使用本机真实日期与 SQLite，首次启动为空任务。

使用、数据路径、导入原型数据及版本范围见 [Windows 安装版说明](docs/Windows安装版说明.md)。

仓库包含源码、文档、测试、图标和安装配置；依赖、运行数据、临时验收产物及 `dist/` 构建产物不提交。

在 Windows 上使用 Node.js 24 安装依赖、启动客户端或生成安装包：

```powershell
npm ci
npm run desktop
# 生成 dist/ToZ-Setup-0.4.9-x64.exe
npm run build:win
```

当前视觉按用户提供的 macOS 官网介绍截图调整：中性灰白窗口、半透明侧栏与浮窗、蓝青桌面背景，以及紫/橙/粉项目标记；菜单选中、主按钮、日期选择和表单焦点统一采用中性灰，深色选中背景为半透明灰色。主题集中在 `prototype/macos-theme.css`，保留原有任务和日期规则。

- [视觉与交互规范](docs/视觉与交互规范.md)：颜色、布局、组件、动效和原生实现边界。

## 预览

需要 Node.js 22 或以上，无需安装 npm 依赖：

```powershell
npm start
```

浏览器打开 http://127.0.0.1:4173 。使用 HTTP 预览；直接双击 HTML 时浏览器可能阻止 ES 模块加载。

## 可体验的交互

分区、任务与子任务支持右键菜单；子任务可改名，三类内容可移入回收站并恢复。分区删除可迁移任务及周期或连带删除，保留所有日期和足迹。选择的开始日期晚于完成日期时，完成日期自动跟随到开始当天。

任务右键可通过二级菜单移动到其他分区。回收站支持单项彻底删除与一键清空，确认后执行；周期的已删除期次不会再次补回。设置和回收站的标题、关闭按钮固定，内容独立滚动。

子任务支持可选开始和截止日期：点击添加框旁的日历，或编辑已有子任务。两日期需同时设置且在主任务计划范围内；主任务改期不能越过已有子任务。列表、详情与浮窗同步显示，改期追加主任务足迹。

农历每月 / 每年周期支持月日与闰月规则；项目支持双击改名、自定义颜色和拖动顺序；浮窗可下拉筛选项目。新建任务默认置顶并排在已有置顶任务前面，可取消置顶；长按菜单、项目或任务可拖动排序，也支持 Alt + ↑ / ↓，顺序本地保存并跨窗口同步。

新建可安排每天、工作日、周末、每周多选、每两周、每月、月末、季度、每年及自定义 1–99 天 / 周 / 月 / 年周期，可设置重复结束日期（限制最后一期的执行日）。计划起止日期的日差决定每期计划跨度，表单预览同时显示执行日与完成日；最后一期可在重复结束后完成。每期任务独立保存，详情可停止重复；离线后补齐缺失期次。“即将到来”每个周期仅提醒最近的一期，完成、删除或进入今日后自动展示下一期。分区和全部任务默认只显示每组当前待处理的一期，可“展开其余期次”；已完成历史保留，关键词与全局搜索可查找全部匹配期次。任务列表和悬浮窗可直接展开子任务并勾选（浮窗默认收起），详情添加框为圆角灰底；任务足迹按完成、重开、新增、开始等类型显示语义色。

甘特图支持项目分组、周/月时间轴、筛选、详情与排期调整，普通任务使用连续区间；周期任务在月历和甘特图仅标记每期日期，甘特图按分区把同一周期合并成一行；侧栏可直接输入全局搜索。应用采用黑白标识和灰色导航图标。

创建任务、筛选与项目导航、首次开始、子任务添加/完成、任务完成/重开、日期调整和延期原因、时间线、JSON 导出。两侧共享同一份内存数据，并保存在当前浏览器 localStorage；调整浮窗透明度、折叠、明暗壁纸和画布内拖动。

月历将普通跨日任务合并为每周内的连续长条；周期任务取消延续显示，仅在每期对应日期点性展示，默认最多 5 行，超出可展开本周全部事项；支持切月、回到今天、按日期新建和查看详情。日期选择器及任务日期同时显示农历。

安装版新安装默认深色；支持计划起止区间逐日展示，实际开始后保留在今日。浮窗可通过“添加待办”打开独立小窗口，无需显示主界面，支持完整日期、周期与分区表单；小窗口标题栏与主界面统一，随浅深主题切换。浮窗标题空白处双击展开 / 收缩，折叠后轮播今日任务。

快捷键：`Ctrl+K` 搜索、`N` 新建、`Esc` 关闭弹窗。

## 原型边界

演示日期固定为 **2026-10-20**，便于核对延期与持续天数。当前原型和安装版子任务均支持主任务范围内的可选起止日期，父任务足迹记录子任务变动；独立提醒、独立历史详情与工时属于后续目标。浏览器透明只是画布内效果，窗口置顶仅模拟状态；原型没有原生托盘、SQLite 或安装版的导入恢复。安装版已具备原生窗口、托盘、SQLite 及 JSON 恢复。浏览器数据清理后可能丢失；两种形态都没有实际工时计时。
