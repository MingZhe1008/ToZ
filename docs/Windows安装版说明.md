# ToZ Windows 安装版 v1.1.5

本页仅说明 Windows。Android 手机 / 平板的测试安装包、操作与构建见 [Android 安装与开发说明](Android安装与开发说明.md)；两端复用账号同步协议，安卓设备实际联机仍待验收。本轮不重建 Windows 安装包。

2026-10-25 文档核对：本页正文为当前操作说明，底部版本章节保留演进记录。新会话先读 [项目现状](项目现状.md)；后续按 [文档维护规范](文档维护规范.md) 更新。

## v1.1.5：统一登录数据提示样式

有离线任务时，登录前的数据处理提示改为随深浅主题变化的圆角应用弹窗，启动页和设置页一致。选择“保留本机任务，进入账号”或“复制本机任务到账号”后，点击“继续登录”；未选择时不能继续，默认焦点是取消。关闭、Escape 或取消均不执行登录和复制；验证码保留，可继续使用。选择期间本机数据更新时会提示重新选择，原离线数据仍保留。

## v1.1.4：修改账号昵称

点击左下角头像账号入口 → 修改昵称，填写后保存。最多 30 个字符，支持中文和表情；留空保存则恢复默认显示，侧栏显示邮箱前缀。取消不会更改昵称。修改需要登录和网络，昵称随账号同步到其他电脑；侧栏、账号菜单与账号页优先显示昵称，菜单及已绑定身份保留邮箱。昵称不是登录凭据，也不改变任务、绑定邮箱或账号身份。

## v1.1.3：托盘提示与账号状态一致

Windows 托盘悬停提示不再固定为“ToZ · 离线待办”：未登录显示“ToZ · 离线使用”，登录后随待同步、同步中、云端已同步或同步待处理更新，与客户端状态一致。登录、退出和同步更新都刷新提示。程序文件描述及应用内新建快捷方式说明改为“ToZ 待办与云同步”；旧 Windows 快捷方式或系统缓存的说明不保证自动重写。服务端无需更新。

## v1.1.2：头像账号菜单与明确的同步状态

左下角设置和回收站图标改为圆形头像账号入口，显示邮箱前缀或“离线使用”。点击展开菜单，可打开账号与同步、设置，上传 / 恢复默认头像，或退出账号；未登录时可从菜单登录，头像操作不可用。回收站仍从顶部“任务 → 打开回收站”进入。

上传头像选择不超过 5 MB 的 PNG / JPEG / WebP，居中裁成 128×128 PNG，按圆形展示；保存到账号后自动同步到其他已登录电脑，换电脑后无需重新上传。此操作需要网络，失败保留原头像。

左上角不再固定写“本地”，而是显示“已登录”或“离线”，悬停可看账号及同步状态。底部显示“本机已保存 · 待同步 / 同步中 / 云端已同步 / 同步待处理”，离线显示“离线使用 · 本机已保存”。本机保存成功与云端同步成功分开判断，新修改尚未上传时不会显示为云端已同步。保存失败始终优先提示；浮窗底部与列表说明使用相同语义。账号与同步页面打开时立即使用当前账号快照，后续通过推送更新，不再先显示未登录再等待轮询。

## v1.1.1：先选择登录或离线

未登录启动时先出现独立欢迎页，可输入邮箱验证码“登录 / 注册并进入”，也可直接点击“离线使用”。选择前不创建任务主窗口和浮窗；关闭欢迎页退出程序。未登录的自动启动同样先显示欢迎页，不受“自启动收至托盘”跳过。已有保存会话直接进入，保留原有自启动最小化习惯；断网不强制退出已登录的本地副本。

退出账号后隐藏任务窗口、浮窗和设置，返回欢迎页；选择离线后显示原本的离线任务，也可重新登录其他账号。离线模式下仍可在设置 → 账号与同步登录；设置入口用于后续管理，不再是启动登录的必经入口。此版本只调整客户端启动与窗口流程，服务器无需重新部署。

## v1.1.0：邮箱账号与 Windows 云同步

“设置 → 账号与同步”支持邮箱验证码登录 / 注册，绑定其他邮箱，以及立即同步。多台电脑使用同一账号，约每十五秒交换任务、分区、子任务、周期与足迹。离线可继续编辑，恢复网络后重试；任务排序、阅读、启动与窗口设置各电脑独立。

首次登录可选择保留本机离线数据，或将其复制到账号（仅首次建立账号副本时执行）。账号数据库位于数据根目录 `accounts/<账号哈希>/toz.sqlite`；v1.1.1 退出后返回欢迎页，选择离线使用后显示原离线数据，不删除账号副本。数据页当前路径与导出 / 恢复均针对正在使用的副本。同步硬删除会传播，旧备份和安全副本仍保留。

同一任务的竞争修改暂停同步，账号页可选择冲突项保留本机或云端；涉及分区 / 周期关联冲突时可能需要选择完整一侧。确认前后版本变化会拒绝处理，替换前另存安全副本。服务已部署至 IP HTTPS，邮箱发送已联调；手机号绑定与登录待短信接入。完整说明和限制见 [云同步部署说明](云同步部署说明.md)。

## v1.0.0：桌面体验统一

主窗口采用系统字体、短标题、紧凑元信息与绿色完成状态。任务行“更多”与右键菜单保留改期、编辑、置顶、分区迁移和导出。浮窗顶部仅保留更多 / 折叠，更多使用原生菜单，收起时也不裁切。标题栏提供 ToZ / 任务 / 视图 / 帮助四组菜单，F10 与方向键可操作。“任务”仅保留添加待办、打开回收站；“视图”仅保留浅色外观、深色外观、桌面浮窗、恢复浮窗交互。顶栏菜单单击展开，再次单击同项收起，切换组需点击；支持外部点击、Escape 与方向键。任务 / 视图 / 帮助与标题栏“悬浮框”按钮共用文字样式：继承相同字体族、11px、400 字重、默认 var(--muted)，悬停 var(--accent)。设置使用独立窗口，v1.1.0 分五类（新增账号与同步），阅读偏好同步主窗、浮窗、新增窗与设置窗。安装器采用深色侧栏、卡片选项和三步导航，由内嵌 NSIS 执行安装。

## v0.4.10：取消新建默认置顶

新建普通任务、独立新增窗口创建的任务及新生成的周期期次均默认不置顶。保留图钉手动置顶 / 取消置顶功能，已有任务的置顶选择不自动改变，已有置顶任务继续优先显示。

## v0.4.9：添加待办入口

任务列表右上角由单独加号改为“＋ 添加待办”，点击打开原新增表单，也可继续使用 N 快捷键。

## v0.4.8：子任务开始与截止日期

在“添加子任务”框旁点击日历，可设置名称、开始日期与截止日期；直接回车或加号仍添加不设日期的子任务。已有子任务可通过编辑图标、双击或右键修改日期，也可点“不设日期”清空。列表、详情与浮窗同时显示。

日期为可选项，但设置时需成对填写，且包含在主任务的计划开始 / 完成范围内（可与边界同日）。主任务还没有完整起止日期时，先“调整计划”补齐。日历会禁用范围外日期；主任务缩短范围如果越过已有子任务，会提示先调整子任务。删除子任务后可缩短主任务，恢复该子任务时仍需满足范围。改名及改期追加主任务足迹；旧清单无需处理。

## v0.4.7：分区与全部任务收起重复期次

分区与“全部任务”默认只显示每个周期当前待处理的一期：实际已开始者优先，否则选计划开始最早的未完成一期（无开始日期时使用计划完成或执行日），保留逾期待办。完成或删除本期后自动显示下一期；重开后重新选择。已完成历史及同名普通任务单独保留，不会删除预生成期次。

在周期行点击“展开其余 N 期”查看和操作每一期，再点收起；各视图独立保留本会话的展开状态。分区侧栏数量按合并后的未完成待办计数；进度仍按实际期次数量计算，展开不会改变完成比例。关键词筛选和侧栏全局搜索可直接查到收起的期次，清空搜索恢复原视图。今日、浮窗与已完成历史沿用原有规则。

## v0.4.6：甘特周期合并日期点与日期说明

同一分区内的同一周期在甘特图只占一行，右侧在每期执行日画点；不再给每一期各画一条跨日长条。点击点打开该期详情，开始、完成、改期只操作本期，完成点为绿色。普通任务仍显示时间条。周期被迁到不同分区时，按实际归属分别显示。

选择重复后，上方计划开始用于起算周期，计划完成与开始的日差用于定义每期计划跨度；“重复结束日期”只限制最后一期何时执行，不要求该期在此日前完成。表单说明跨度，预览列出“执行日 → 计划完成日”。例如每月 22 日、10/22 → 11/04，后续为 11/22 → 12/05；若重复结束设 11/30，保留 11/22 这一期，但不再安排 12/22。

## v0.4.5：即将到来仅显示最近一期

“即将到来”中的重复任务每组只提醒最近的未来一期，侧栏计数同步。最近一期完成、删除、开始或到期进入今日后，自动展示下一期；重开未来的较早期次后重新选择。当前计划开始最早者优先，没有开始日时使用完成日，置顶与手动顺序不影响“最近”的判断。普通任务及同名不同周期分别保留。此操作只收起后续提醒，所有期次仍可在日历、甘特图查看，或在全部任务 / 所属分区展开与搜索。

## v0.4.4：新增窗口标题栏统一

新增待办小窗口采用与主界面一致的 38px 中性标题栏（v1.0.0；v0.4.4 原为 34px）；深色显示深灰背景与浅色窗口按钮，浅色显示浅灰背景与深色按钮，打开时及主题切换时同步。保留原生最小化、最大化、关闭、拖动和缩放，取消深色窗口上突兀的白色系统标题栏。

## v0.4.3：默认置顶、浮窗新增与周期点性展示

- v0.4.3 曾默认置顶；自 v0.4.10 起取消自动置顶，新建普通任务及新生成周期期次均默认不置顶。已有任务的置顶选择保留，可通过任务更多 / 右键菜单手动置顶或取消置顶。
- 浮窗点击“添加待办”（或按 N）打开独立小窗口，无需打开主界面。支持日期、周期、分区和说明，默认使用浮窗筛选分区；可直接新建分区并保留草稿。保存成功关闭小窗口并同步；取消、Esc 或关闭不创建任务，重复点击保留当前草稿。标题和操作按钮固定，表单内容可滚动；窗口标题栏与应用浅深主题一致。
- 周期任务取消在月历上的延续显示，只在每期对应日期显示，例如每周指定星期、每月 10 日；开始、延期或完成不拉长该标记。任务历史及今日待处理集合仍保留；当前甘特图也按同组一行日期点展示。

## v0.4.2：彻底删除与固定设置标题

- 回收站每项增加「彻底删除」，顶部提供「一键清空」。执行前展示范围、数量与不可恢复提示，默认焦点为取消；清空处理整个回收站，不受搜索条件影响。空回收站禁用清空。
- 删除分区会同时移除仍在该分区内的已删除任务，已迁出的正常任务保留。单独清除子任务会保留父任务原有足迹。任务彻底删除会移除其子任务与 SQLite 足迹。
- 周期任务的已删除本期记录为排除日期，避免离线补齐时再次出现；排除信息随备份和恢复保留。其他期次继续按原规则安排。
- 彻底删除无法从回收站恢复。旧备份、恢复前安全副本和已导出文件不会随之清除；主动恢复旧备份仍可能找回其中的数据。
- 设置与回收站采用固定标题、关闭按钮和内部内容滚动。设置滚到底部也可直接点击右上角关闭，适配浅色、深色和较矮窗口。
- 普通保存仍不能硬删除历史；彻底删除使用独立事务和确认时的数据版本。另一窗口更新后须重新确认删除范围，避免清空新到达的内容。

## v0.4.1：任务右键切换分区与切月修复

- 任务右键选择「移动到分区」：悬停、点击或方向右键展开二级菜单，显示已有分区、颜色与当前归属的勾选。选择后立即同步客户端和悬浮窗。
- 迁移保留首次实际开始、计划日期、子任务、置顶与手动顺序，追加「移动分区」足迹。周期任务仅迁移所选本期，其余期次与模板保持原归属。回收站分区不出现在选项中。
- 二级菜单支持上下选择、左右展开/返回、回车确认与 Escape 关闭；靠右时向左展开，窄悬浮窗使用两列适配。
- 修复新建和调整计划中的日期选择器：点击左右箭头（包括箭头图形）连续切月不会关闭面板，支持跨年；浏览月份不改写日期，点击日期才填入，点外部或 Escape 可关闭。

## 安装

运行 `dist/ToZ-Setup-1.1.5-x64.exe`。安装包包含运行时，离线使用不需要 Node.js、浏览器服务或网络；账号登录及多电脑同步需要网络。

安装向导分为安装位置、使用习惯、准备就绪三步。首次安装默认“仅当前用户”、创建桌面和开始菜单快捷方式、自启动关闭；升级读取已有安装范围、目录和当前账户的自启动状态。支持浏览本机目录以及中文、空格路径；返回上一步保留选择。所有用户安装需要 Windows 管理员授权，取消授权可返回选择当前用户。快捷方式按所选范围创建；任务、外观和自启动按当前 Windows 账户独立保存。安装过程中显示细圆角灰色轨道、低饱和绿色填充、右侧阶段百分比；进度对应提取 / 校验 / 引擎完成 / 偏好保存节点，等待引擎时停在 30%，不按时间虚增；工作期间不能取消或关闭向导。

完成页可直接启动 ToZ。Windows“设置 → 应用”中可卸载。卸载会移除程序、快捷方式和自启动入口，默认保留任务与备份。

首版为 Windows x64，已在当前 Windows 环境中构建验证。安装包尚未配置发布者代码签名；正式公开发行时可补充签名。

## 客户端设置

左侧“设置”、ToZ 菜单、托盘或 Ctrl+, 可打开独立设置窗口，重复打开复用已有窗口。从浮窗进入不唤起主窗口，关闭设置也不关闭主窗口；原生标题栏固定，四个分类的右侧内容独立滚动：

- **外观与阅读**：浅色 / 深色；较大文字；减少透明度；浮窗背景不透明度。新安装默认深色、88% 底色，已有主题和透明度保留。阅读设置保存并同步主窗口、浮窗、独立新增窗口与设置窗口；减少透明度不改写原不透明度值。
- **启动与窗口**：登录后自动启动、自启动时收至托盘、关闭主窗收至托盘、显示浮窗、窗口始终置顶、桌面快捷方式及穿透恢复。真实启动设置仍读取系统状态确认。
- **数据与备份**：打开数据目录、导出完整 JSON、恢复 / 导入备份、回收站；自动备份按最近十四份日快照保留，恢复前先创建安全副本。
- **关于**：版本与退出 ToZ。

开启穿透后，通过托盘“解除鼠标穿透”、Ctrl+Alt+T 或设置中的“恢复浮窗交互”恢复。原生浮窗顶部“更多”提供添加、折叠、窗口始终置顶、穿透、设置与工作台入口；它与任务菜单的“置顶任务”含义不同。

浮窗是独立的透明无边框窗口，可拖动和调整尺寸。普通悬浮窗不保证按 Win+D 后仍留在桌面，未实现桌面图标后方嵌入。

## 甘特图与搜索

左侧新增“甘特图”：按分区分组并可收起，周 / 月切换、前后导航、回到今天；左侧任务列与顶部日期保持固定，时间轴可横向滚动，今天以灰色竖线标记。支持分区、状态和关键词筛选，普通任务时间条显示区间天数、子任务完成比例和跨边界提示；重复任务同组一行，每期只画日期点，不显示跨度长条。点击时间条或日期点查看对应任务 / 期次详情；普通任务行的日历按钮打开“调整计划”，使用现有历史记录与日期保护。未排期任务保留并可直接设置排期，区间外任务可定位。

当前通过排期弹窗修改日期；时间条拖拽、依赖连线、负责人和基线对比不在本版范围。

侧栏搜索框支持直接输入，搜索所有任务（含未来与未排期），清空后回到搜索前视图；Ctrl+K 聚焦侧栏搜索。甘特图自身还有不离开当前视图的局部搜索。

应用、托盘、安装包和桌面快捷方式图标改为黑底白色 tz 标识；菜单图标采用灰色，分区彩色标记仍用于辨认分区。

## 灰色交互主题

菜单选中采用 Codex 风格的灰色半透明背景。任务行、主按钮、日期选择器、分区下拉菜单、设置开关、输入焦点、文本选区和浮窗置顶状态全部使用中性灰；浅色 / 深色模式分别适配。分区标记仍用于区分分区，延期保留橙色提示。

已完成任务使用清晰的完成勾与删除线，文字与元信息保持可读对比度。日历与列表中的完成状态使用绿色底色或完成勾（v1.0.0 浅色标记 #2F8050，深色标记 #94D7AB）；未完成事项使用所属分区颜色。改期弹窗将快捷完成日期按钮独立成行，避免与计划起止输入框重叠。

## 周期任务与子任务

新建任务的“重复安排”支持每天、工作日（周一至周五，不含法定节假日判断）、周末、每周指定多个星期、每两周、每月、每月最后一天、季度、每年，以及每 1–99 天 / 周 / 月 / 年的自定义间隔。可选结束日期，按每期计划开始日期判断是否在结束范围内。

每期是独立任务，首次实际开始、完成、子任务与延期历史分别记录。“即将到来”每组仅显示最近一期，其余期次保留，可从全部任务或日历查看。周期实例在月历仅标记本期 repeatDate，取消延续显示；逾期仍保留在今日，开始、手动延期和完成都不改变月历的本期日期标记。延期本期不会移动后续周期；编辑标题、说明、分区和子任务只影响本期。普通月 / 年周期遇到不存在的日期取当月最后一天，下次仍按原锚点安排（1 月 31 日 → 2 月末 → 3 月 31 日）；月末模式始终取月底。

应用打开后预生成未来 45 天，并至少保留一个未来期次；浏览远月日历 / 甘特图时继续按需生成。退出期间不运行后台进程，重新打开会补齐从起始日到当前窗口范围内的缺失期次，不覆盖已有完成或延期历史。周期规则与实例都纳入 SQLite、导出备份及恢复，实例去重。完整备份保留周期运行状态；仅导出一个任务时，导出的周期处于停止状态，避免恢复单任务时额外生成整组周期。

详情中“停止重复”保留已完成、已开始及当前期次，取消尚未开始的未来排期，取消记录仍留在本地历史内。需要更换周期规则时可停止原周期并新建；本版不提供批量改写已有实例。

列表的“已完成数量 / 子任务总数”可直接展开 / 收起，在列表内完成或重新打开子任务，并与详情中的进度同步。客户端列表与悬浮窗均可展开，悬浮窗默认收起，展开状态与客户端独立；勾选直接保存并同步，不会打开主窗口。展开状态在当前窗口切换视图、保存与勾选时保留，刷新或重新启动后默认收起。悬浮窗子任务过多时在清单内部滚动，重绘后保留滚动位置。添加子任务采用与搜索框相同的圆角灰底样式，支持回车提交。

任务足迹的圆点及标题按事件类型区分：完成绿色，重新打开 / 延期橙色，开始 / 提前调整青绿色，新增子任务 / 内容编辑紫色，创建灰色；同时保留文字，旧版子任务事件也可辨认。

## 数据与任务

安装版首次启动是空任务列表，使用本机真实日期；浏览器原型仍为固定日期的演示。

侧栏“分区”旁的加号可添加自定义分区；新建 / 编辑待办时，分区选择框旁的加号和下拉列表末尾也可以直接新建分区，保留正在填写的待办草稿。空分区也会保存并包含在备份中。标题栏右上角、最小化按钮左侧提供“悬浮框”按钮，单击或双击均切换显示 / 隐藏；一次双击只切换一次。显示时解除鼠标穿透。浮窗标题空白处双击可以展开 / 收缩，原有箭头按钮也可使用。折叠后每 4 秒轮播今日未完成任务，长标题横向滚动；鼠标滚轮可切换条目，点击可打开任务详情。

任务支持新建、编辑标题/说明/分区、子任务、开始、完成/重开、调整计划、逐次延期原因和历史、月历。新建时可指定计划开始和计划完成日期，或选 1 天、3 天、1 周、2 周快捷区间。开始日不能晚于完成日；计划起止与首次实际开始分别保存。

普通任务在月历按区间每天展示同一个任务，首尾均包含：如 20 日开始、25 日截止，20–25 日每天可见。未填计划开始的旧任务使用已有的首次实际开始；仍未开始则从计划完成日显示。延期扩展结束日期；逾期未完成的任务继续延伸至当天。完成后止于实际完成日。跨日展示共用同一个任务，完成任意一天即完成整个任务。当前每周默认最多五行连续任务条，可展开该周全部事项；月任务数按任务去重统计。周期任务例外：取消延续条，仅在 repeatDate 对应日期点性展示，延期与实际完成日期保留在详情，不移动月历期次。

已实际开始或已到计划开始日的未完成任务进入今日和浮窗，即使截止日在未来也不会消失。首次实际开始仍只在点击“开始任务”时记录；手动调整计划起点需追加历史。首次开始日期及最初计划日期由 SQLite 与应用逻辑共同保护，不因延期改写。持续天数是经过的日历天数，不是实际工时。

数据目录为当前用户的应用数据目录 `ToZ/`，通常为 `%APPDATA%/ToZ`，以设置页显示的实际路径为准：

- `toz.sqlite`：任务、事件、设置与窗口位置。
- `backups/ToZ-YYYY-MM-DD.json`：每个写入日期的最新完整任务快照，按文件数量保留最近 14 份。
- `before-restore-*.json`：每次恢复前自动保存的安全副本。

主界面、浮窗与新增小窗口共享数据库写入服务，通过版本号拒绝旧状态覆盖，并在成功提交后同步刷新。首次开始只写一次，普通保存历史只能追加；经确认的回收站永久删除与全量恢复使用独立事务。备份恢复是显式全量替换，会先预览任务数量并要求在客户端确认。

浏览器原型的数据不会自动带入安装版。需要时先从原型“设置 → 数据与备份”导出 JSON，再到安装版“恢复 / 导入备份”选择该文件；这会替换安装版当前任务，操作前会自动备份。

子任务支持一层清单及主任务范围内的可选起止日期，足迹保存在主任务中；Windows 云同步见下文；子任务独立提醒 / 日历行、实际工时计时、手机号验证码和 iOS 未实现。

## 构建与验证

开发需要 Node.js 24：

```powershell
npm ci
npm run install:runtime
npm run build:win
```

默认只对本轮修改内容及其直接影响的行为做定向测试或交互检查，纯文档 / 技能修改只检查内容、引用和差异，不重建安装包。构建不会自动附带完整测试或验收。仅当用户明确指定时，才执行对应完整流程：`npm test` 为全量领域 / 存储测试，`npm run smoke` 为完整源码隔离验收；完整打包程序验收同样需要用户明确指定。不要因提交、推送或打包自行执行整套流程。

若 Node 下载通道无法访问 GitHub，可以从 Electron 官方 release 下载与锁定版本对应的 Windows x64 ZIP，按 npm 包中的 `checksums.json` 校验 SHA-256 后放入 `node_modules/electron/dist`，并写入 `node_modules/electron/path.txt` 为 `electron.exe`。此前交付环境的运行时已按此方式校验；新克隆仓库不含 node_modules 或运行时，需自行安装。

安装包先由 Electron / electron-builder / NSIS 生成安装引擎，再由 `scripts/build-installer-ui.ps1` 使用 Windows .NET Framework 4.x C# 编译器生成外层向导。`build/installer-ui.cs` 定义 WinForms 深色界面与引擎调用；manifest 使用 asInvoker 与系统 DPI 感知；`build/installer.nsh` 保留引擎快捷方式及卸载逻辑。外层内嵌安装引擎，提取到唯一临时目录并校验 SHA-256；选择所有用户时仅为引擎请求提升权限，外层负责当前账户的启动项。构建不需要额外的 WebView 或第二份 Electron。最终安装包替换内层安装包；删除仅适用于内层字节的 blockmap / latest.yml，当前没有自动更新功能。NSIS 卸载器仍使用原生界面。

`build/generate-installer-art.ps1` 生成引擎 / 卸载器品牌图；`desktop/main.cjs` 定义应用窗口、托盘和文件操作；`desktop/store.cjs` 定义 SQLite 事务与日期保护。安装界面隔离检查使用 `scripts/build-installer-ui.ps1 -Preview`，编译时禁用实际安装，不修改启动项。完整安装、UAC、升级及卸载须另在隔离系统中验证。

静默安装支持 `/S /DESKTOP=0或1 /STARTMENU=0或1 /AUTOSTART=0或1 /D=安装目录`，其中 `/D=` 必须放在最后，目录不额外加引号（支持空格）；省略 `/AUTOSTART` 时保留当前账户已有状态。可加 `/currentuser` 或 `/allusers` 选择范围；`/allusers` 需要提升权限。

参考：[Electron 启动项 API](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows)、[electron-builder NSIS 配置](https://www.electron.build/nsis/)。


## v0.3.0：农历、分区与排序

- 周期选择新增“农历每月 / 农历每年”，可选农历日、农历月（每年）及闰月安排。默认从所选公历开始日期对应的农历月日填入，也可手动改选。普通月、含闰月、仅闰月分别处理；仅闰月在无对应闰月的年份跳过。三十遇小月取廿九，下次大月恢复三十。农历周期支持 1900–2100 年，结束日期按公历、包含当天。
- 月历、日期选择器、任务起止日期、首次开始、延期足迹、甘特图与浮窗显示农历。实际保存日期仍为公历，不修改旧记录。
- 双击侧栏分区可改名、配色，也可点击分区右侧编辑按钮。支持系统色盘和常用色。更名同步已有任务与后续周期，每个所属任务追加分区更名记录，日期与原有事件不变。
- 悬浮窗下拉筛选“全部分区 / 指定分区”，进度、清单及缩略轮播均按所选分区计算；筛选选择保存在本机。
- 日历跨日任务在每周内合并为一根横条，跨周续接，已完成采用绿色。默认最多五行，展开本周可查看全部，收起后恢复五行。
- 任务行、任务详情、日历条和普通甘特时间条提供图钉按钮；甘特周期汇总行需先点击日期点，再在本期详情置顶。任务置顶在主窗口和浮窗同步；这是任务排序，浮窗头部的图钉仍控制窗口始终置顶。
- 长按约 0.4 秒后拖动侧栏菜单、分区或任务，插入位置显示灰色线。菜单、分区分别排序；任务在相同完成状态与置顶状态内排序，顺序为全局共用。时间条拖动只调整排列，不改变起止日期。Alt + ↑ / ↓ 也可调整选中项顺序，Esc 取消拖动。
- 颜色、顺序、筛选和任务置顶随本地数据、备份与主窗口 / 浮窗通信同步；兼容旧版任务与备份。农历引擎为本地内置 lunar-javascript 1.7.7（MIT），不发起联网换算。

## v0.4.0：右键编辑、删除与回收站

- 分区右键提供名称 / 颜色编辑、新建分区和删除。删除可选择把任务及周期迁移到其他分区，或把分区及所属任务一起移入回收站并停止重复。删除最后一个可用分区时自动创建“未分区”。已有名称保留在回收站中，同名新建时提示先恢复。
- 主列表、详情、日历时间条、甘特图和悬浮窗中的任务右键支持编辑、置顶、完成 / 重新打开、开始、调整计划、添加子任务及删除；周期另有“停止后续重复”。删除周期任务默认只删除本期，后续期次继续，不会补回已删除期次。
- 主列表展开子任务、详情及悬浮窗子任务支持右键编辑名称、完成 / 重新打开、删除；也可双击名称或点击编辑图标。悬浮窗中编辑名称会打开主窗口编辑，删除 / 勾选直接同步。
- 删除采用可恢复的回收站，保留首次实际开始、最初计划、延期、完成状态、子任务与所有足迹。侧栏设置旁的回收站图标，以及设置 → 数据与备份中的“打开回收站”可恢复分区、任务和子任务。v0.4.0 当时没有永久清空入口；v0.4.2 已提供经确认的逐项彻底删除和全量清空。
- 已删除子任务不计入进度，也不阻止完成父任务；恢复未完成子任务时，若父任务已完成则自动重新打开并记录足迹。随分区删除的周期恢复后保持停止，已有任务可恢复；迁移方式删除后恢复原分区为空，原任务继续留在目标分区。
- 右键菜单使用统一灰色透明背景，支持 Esc 关闭、方向键选择，也支持菜单键 / Shift + F10。
- 新建及调整计划时，选择的开始日期若晚于当前完成日期，完成日期自动推到开始当天；有效区间与未安排完成日期保持原样。修改现有任务保存时仍记录完整日期变动，不改首次实际开始。
