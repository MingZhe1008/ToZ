# ToZ 视觉与交互规范

版本 v0.5 · 2026-10-20

## 设计方向

“安静的桌面，清楚的时间。”依据用户提供的 macOS 官网介绍截图，使用中性灰白窗口、半透明侧栏、蓝青色桌面背景，以及清晰的多彩项目标记。菜单选中参考 Codex 的灰色半透明底；主按钮、日期选中、设置开关和输入焦点统一使用中性灰，不使用蓝色选择背景。Windows 客户端保留 Windows 的窗口行为和键盘习惯，正式原生标题栏使用最小化、最大化、关闭，不照搬红黄绿窗口钮。

主客户端是完整工作台；浮窗是轻量的今日便签。主视觉记忆点是任务详情中的“首次开始”锁定信息和连续延期时间线。

## 布局

- 主窗口建议 1180×780 逻辑像素，最小 960×640。
- 左栏 184px，详情 320px，中栏弹性；小尺寸详情改为覆盖式抽屉。
- 浮窗默认 320×480，可折叠；小屏内部滚动，不能裁掉主要操作。
- 浏览器原型提供并排、客户端、桌面浮窗三种预览。小屏并排自动纵向排列；预览页面本身也可滚动。
- 原型右侧壁纸是 CSS 绘制的山丘与天空，无外部图片资源。

## 组件与状态

| 组件 | 正常 | 交互与异常 |
| --- | --- | --- |
| 完成圆钮 | 细描边 | 悬停高亮；完成为高对比度灰色底勾；日历完成勾用绿色；可重新打开 |
| 任务行 | 标题 + 单行元信息 | 选中半透明灰底与细边；完成划线；延期使用文字徽标 |
| 只读起点 | 锁图标 + 首次日期 | 不放日期编辑控件；说明首次开始不受延期影响 |
| 改期弹窗 | 当前→新日期、原因 | 起止日期一组，快捷完成日期独立一行；同日禁重复提交；日期无效就地提示；保存后给出明确结果 |
| 时间线 | 细线串联圆点 | 延期显示旧→新；原因次行；开始与完成使用不同图标 |
| 空列表 | 简短说明 | 保留新建入口；搜索为空提示调整关键词 |
| 保存状态 | 底部本地保存标识 | 写入失败持续显示，不显示成功反馈 |
| 浮窗置顶 | 图钉开关与文字 | 原型标注为状态演示；正式版由原生 API 返回成功后更新 |

## 核心微交互

- 主任务选中后更新详情，同一份数据同时刷新浮窗。
- 点完成时不强行开始任务；有未完成子任务时提示先处理子任务。
- 改期弹窗显示完整日期，延期成功说明起点未改变。
- 新建后聚焦新任务；浮窗输入与客户端输入通向同一任务集合。
- 透明度滑块只改变面板底色 alpha，不降低文字 alpha。
- 动效 140–220ms，只用于进入、焦点与状态反馈；遵循 `prefers-reduced-motion`。
- 快捷键 Ctrl+K 聚焦搜索、N 打开新建（输入控件内不触发）、Esc 关闭弹窗；正式版浮窗恢复快捷键建议 Ctrl+Alt+T，注册冲突时允许改键。

## 可访问性

所有图标按钮有中文可访问名称；任务完成钮使用 `aria-pressed`；当前导航和当前预览模式有选中语义。键盘焦点可见。弹窗使用原生 dialog，正确返回焦点。正常文字应在浅色/深色壁纸与透明度范围内逐一验证对比度；正式版在复杂壁纸或高对比度模式使用更不透明的降级底色。

## 实现标记

本稿不把浏览器 CSS 透明当作系统透明。原生浮窗、全局置顶、穿透、托盘与保存到 SQLite 都是正式客户端工作。设计原型演示布局、任务交互和时间历史；实现状态详见开发需求文档第 12 节。

## v0.2 日历补充

- 新建与延期表单统一使用自定义日期选择器：中性白底、浅灰边框、蓝色选中态；今天用红色小圆点标记，相邻月份日期减弱显示。选定后自动填入并关闭，支持上/下月和方向键移动，Esc 先关闭日历、再次按下再关闭对话框。
- 新增独立“日历”导航。月历占据列表与详情区域，右侧详情按需覆盖打开；原有今日列表与浮窗保持可用。
- 月历周一开始，日期单元默认最多 5 项；超出时“+ N 项 · 展开”，展开后显示全部并提供收起。格子随内容增高，不截断事项；整个月历区域可滚动。
- 按项目使用紫、橙、粉的浅色底和对应色标区分；已完成划线，同时保留完成标记。点击标题可看详情，点击完成钮直接更新状态。
- 小屏保持七列日历，在月历内部横向滚动，避免挤压日期；页面本身不产生横向溢出。

## v0.3 macOS 参考配色

- 以用户截图中的系统窗口和多彩日历为参考，不把整个产品染成单一品牌色；主体始终保持中性。
- 交互强调蓝、项目分类色、完成与告警语义色分别使用；蓝青色壁纸只负责烘托透明材质，不改变文字颜色。
- 颜色为 Web 原型中选定的近似值，正式 macOS 原生客户端应使用动态语义颜色。参考 [Apple Color 规范](https://developer.apple.com/design/human-interface-guidelines/color)；当前 Windows 前端不读取 macOS 系统强调色设置。
- `macos-theme.css` 集中管理主题变量与材质，原布局样式已去除绿调。保留所有日期与任务数据规则。

## v0.2.0 增补

列表子任务计数为灰色展开按钮，展开后沿细分隔线缩进显示，完成勾选与详情同步。添加子任务采用 9px 圆角灰底容器，加号内置、焦点环围绕整体。周期表单使用浅灰分组面板，常见预设与自定义间隔分层呈现，多选星期维持灰色选择。足迹以绿色表示完成、橙色表示重开 / 延期、青绿色表示开始 / 提前调整、紫色表示新增子任务 / 编辑，所有事件保留文字标签。


## v0.3.0 补充

保持黑白标识、灰色菜单图标与半透明中性选中背景。项目色可自定义，完成条使用苹果风格绿色；主按钮和表单焦点仍采用灰色。日期选择器每格上公历、下农历；任务日期文字公历后附农历。项目编辑提供圆角色盘与常用色，浮窗筛选使用统一圆角下拉。

月历按周叠放日期背景与任务长条，横条跨多个日期，周边界以续接箭头 / 圆角区分。默认五行，展开按钮单独一行，避免覆盖日期或任务。任务图钉与窗口图钉分离，未置顶轻灰、悬停清晰，已置顶保留灰色底。长按拖动时原项淡化，插入线清晰，不出现蓝色选择底。
